# 공공데이터 제공신청 문안

- 신청 경로: 공공데이터포털(data.go.kr) → 데이터 요청 → 공공데이터 제공신청
  (대상 기관: 부산광역시 / 담당: 교통국 대중교통과)
- 참고 데이터: [부산광역시_버스노선별 승하차 정보](https://www.data.go.kr/data/15123610/fileData.do) (2023-07-31, 1회성)

---

## 제목
부산광역시 시내버스 노선별·정류장별 시간대별 승하차 정보 최신 데이터 제공 요청

## 요청 데이터
1. **시내버스 노선별·정류장별 30분 단위 승차·하차 건수**
   - 기간: 최근 3개월 (일자별, 어려우면 요일 유형별 평균: 평일/토/일·공휴일)
   - 항목: 기존 공개 데이터(15123610)와 동일 — 노선번호, 정류장순서, 정류장코드, 정류장명, 선탑·후탑 건수, 시간대별 승·하차 건수
   - 가능하면 **운행 방향(상·하행)** 구분 포함
2. **정류장코드 대응표**
   - 승하차 데이터의 정류장코드(7자리)와 부산버스정보시스템 Open API의 정류소ID(bstopid, 9자리)·ARS번호(5자리) 대응 목록
3. (가능한 경우) **정기 갱신**
   - 1회성이 아닌 월 또는 분기 단위 갱신 제공

## 활용 목적
같은 구간을 운행하는 여러 시내버스 노선 중 덜 혼잡한 버스를 추천하는 모바일 앱 개발.
부산버스정보시스템 Open API는 실시간 도착정보를 제공하지만 혼잡도(재차인원) 정보가 없어,
노선·정류장·시간대별 평소 재차인원을 승하차 통계로 추정하는 데 사용하고자 합니다.
기존 공개 데이터는 2023년 7월 31일 하루치로, 이후 노선 개편과 요일별 차이를 반영하기 어렵습니다.

## 개인정보 관련
교통카드 번호 등 개인 식별 정보는 필요하지 않으며, 노선·정류장·시간대별 **집계값**만 요청합니다.

## 제공 형식
CSV (UTF-8 선호)

---

## 추가 문의 (선택, 대중교통과 민원/전화용)
부산시에서 서울시처럼 교통카드 승하차 기반 **실시간 버스 혼잡도(재차인원)** 를
부산버스정보시스템 Open API로 제공할 계획이 있는지 문의드립니다.
현재 도착정보 API의 `seat1`, `seat2` 항목이 모두 -1로 반환되는데,
해당 항목의 의미와 향후 제공 계획도 함께 안내 부탁드립니다.
